# African Food Word Puzzle

A word search for ten well-loved African dishes: jollof, injera, fufu, tagine, ndolé, bobotie, thieb, ugali, kachumbari and suya. *Before you cook it, learn to say it.*

**▶ Play it here: [https://chicafricanculture.github.io/african-food-word-puzzle/](https://chicafricanculture.github.io/african-food-word-puzzle/)**

A free game from [The African Gourmet](https://www.theafricangourmet.com/), made to help people learn about African food through play.

## How to play

- Find each word from the list in the letter grid.
- Click or touch the first letter and drag to the last letter.
- Each word in the list links to recipes for that dish on [African Food Recipes](https://www.africanfood.recipes/).
- Use **Hint** if you're stuck, **Reset** for a new grid, and switch between light and dark mode.
- Find every word to finish the puzzle.
